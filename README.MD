Remove AI-generated text overviews and AI Mode in Google search results. Get the extension if you prefer a cleaner, traditional search result page without AI-powered summaries.

> If you use Chromium-based browsers like Edge, Opera, or Brave you can install the extension by visiting the Chrome Web Store link above. Otherwise, you can use [temporary installation](https://support.mfscripts.com/public/kb_view/88/) to load the add-on on Firefox. Safari is not yet supported.

You can also check the latest updates and files on the [releases page](https://github.com/asahisuenaga/hide-google-ai/releases).

If you run into issues, please [create a new issue](https://github.com/asahisuenaga/hide-google-ai/issues/new). Please provide a description of the bug, instructions for reproducing the problem, screenshots, device information, browser, and extension version.
